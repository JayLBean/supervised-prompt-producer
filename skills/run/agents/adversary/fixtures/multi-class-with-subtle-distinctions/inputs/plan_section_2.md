# plan.md §2 — Class definitions (excerpt)

## Bug

The issue describes existing functionality producing wrong,
broken, or unexpected output, with enough detail (steps,
example, error message) that a maintainer can confirm the
defect.

## Question

The issue asks for help understanding existing functionality
or its documented behavior. Answering does not require code
changes.

## FeatureRequest

The issue proposes functionality that does not currently
exist. May be phrased as a question ("how do I do X?") if X
is not yet possible.

### Known borderline

Issues that mix a question with an apparent defect are
borderline. The labeling protocol prefers `Bug` when a
reproducible defect is present, even if the issue's tone is
inquisitive; `Question` when the behavior is documented and
correct; `FeatureRequest` when the question's answer requires
new code.
