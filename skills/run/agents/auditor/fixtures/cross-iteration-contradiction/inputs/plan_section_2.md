# Excerpt: plan.md §2 (Class definition)

**Label space:** {Positive, Negative, Uncertain}

**Class definitions:**

- **Positive:** The user expresses a clearly positive stance
  toward the topic — endorsement, satisfaction, recommendation.
  Positive shape: "I would absolutely use this again."
- **Negative:** The user expresses a clearly negative stance
  toward the topic — complaint, criticism, dissatisfaction.
  Positive shape: "This release broke half my workflows."
- **Uncertain:** The user's stance cannot be determined with
  confidence from the post alone. Includes: posts that contain
  both positive and negative elements (mixed signal); short
  posts that lack qualifying detail; posts where the topic
  itself is ambiguous. The class explicitly exists to allow
  honest abstention rather than forcing a Positive/Negative
  call on insufficient evidence.

**Known borderline cases:**

- Short posts in threaded contexts where surrounding posts
  carry stance the labeled post may inherit. The labeling
  protocol's stated position: judge each post on its own
  surface; do not infer from thread context unless the post
  itself signals stance. (See `plan.md` §10 for the open
  question on whether this position holds across labelers.)
